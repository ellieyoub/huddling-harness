# goal — 하네스 목적

## 매번 달라지는 입력
| 입력 | 값 | 생략 시 |
|---|---|---|
| 대상 화면 | S1 / S2 / S3 중 1개 | 필수 |
| uibowl 키워드 | 자유 입력 | S1 "계산기", S2 "영수증", S3 "아카이브" |

고정 입력: docs/prd.md, docs/design.md, docs/story-service.md

## 사용자
- 본인 1명
- 내부 관계자는 P3 컨셉 확정 때 결과만 봄 (협의는 하네스 밖)

## 범위
- story-work.md 1~7단계 전부
- 사람 승인: P3(컨셉 확정) 1곳, 화면마다 1번

## 완료 기준
S1~S3 Figma 프레임 3개(`S1-final`~`S3-final`, 390×844)가 있고, 화면마다 G5 위반이 0건
(design.md 값·서체 규칙·N1·N2 포함)이며, 화면별 본인 승인 기록이 1건씩 총 3건 있다.
