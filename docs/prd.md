# cally — PRD (v0.1, 디자인 시안 단계)

## 1. 개요
빈티지 계산기(Braun ET66 계열) 모습의 지출 기록 앱.
물품명과 금액만 입력하면 기록되고, 하루가 끝나면 그날 기록이
감열지 영수증 1장으로 아카이브된다.

## 2. 대상 사용자
- 가계부 작성을 매번 포기하는 20~30대 개인
- 깔끔하지만 느낌 있게 소비 패턴을 기록하고 싶은 사용자

## 3. 해결할 문제
- 기존 가계부는 입력 단계가 많아 사용자가 기록을 미룬다.
- 해결: 입력을 물품명 → 금액 2단계로 줄이고, 정리는 하루 마감 영수증이 대신한다.

## 4. 핵심 흐름
1. 메인 화면(계산기)에서 물품명 입력
2. 키패드로 금액 입력 → 기록 완료, 오늘의 테이프에 한 줄 추가
3. 마감 시각이 되면 그날 기록이 영수증 1장으로 자동 출력·아카이브
4. 아카이브에서 지난 날짜의 영수증을 보고, 주별·월별 사용 합계를 확인한다

## 5. 기능 요구사항
| ID | 기능 | 규칙 |
|----|------|------|
| F1 | 지출 기록 | 필드 2개: 물품명, 금액. 기록 시각은 자동 저장 |
| F2 | 기록 수정·삭제 | 마감 전 기록만 가능 |
| F3 | 하루 마감 | 기본 00:00 자동 마감. 수동 출력 없음 |
| F4 | 마감 시각 설정 | 설정에서 사용자가 변경 가능 (시안 제외) |
| F5 | 영수증 아카이브 | 일별·주별·월별 전환. 주별·월별 보기에 기간 사용 합계 표시. 주는 월요일 시작(월~일). 출력된 영수증은 수정 불가 |
- 기록 대상: 지출만

## 6. 어기면 안 되는 것
1. 기록까지 입력 단계 ≤ 2 (물품명 → 금액 → 끝. 사이에 화면 전환·팝업·필수 선택 없음)
2. 출력된 영수증은 변경 불가 (영수증 화면에 수정·삭제 UI 요소 0개)

## 7. 디자인 원칙
> 색·모서리·간격의 기준(SSOT)은 **docs/design.md** (getdesign `cursor`, 수정 없이 사용).
> 서체만 예외: design.md 서체에 한글이 없어 아래 2종으로 고정한다 (harness/rules.yaml에 기록).
> 그 외 이 섹션과 design.md가 다르면 design.md를 따른다.

- 콘셉트: 빈티지 계산기 본체 + 감열지 영수증 메타포
- 형태: 미니멀, 원형 키(`rounded.full` = cornerRadius 9999), `=` 키는 강조색(`primary`)
- 색: design.md `colors`에 정의된 값만 사용. 그 외 HEX 금지
- 서체: 2종만 사용
  - 기본: Pretendard (CursorGothic 대체, 한글 지원)
  - 숫자·영수증: JetBrains Mono (모노스페이스)
  - 금액은 우측 정렬
- 모서리: design.md `rounded` 값만 사용
- 간격: design.md `spacing` 값과 0만 사용 (design.md 컴포넌트의 개별 padding 값은 허용하지 않음)
- 언어: 한국어 UI. 로고·TOTAL 등 일부 라벨만 영문 대문자
- 통화: ₩ + 천 단위 콤마

## 8. 영수증 필수 항목
상단 앱 이름(cally) / 날짜 / 건별 [시각 · 물품명 · 금액] / 건수 / TOTAL / 하단 절취선(점선)

## 9. 시안 범위
- 형식: Figma 프레임, 390×844 세로
- 화면 3개:
  - S1 메인 (계산기 키패드 + 오늘의 테이프)
  - S2 하루 마감 영수증
  - S3 영수증 아카이브 (일/주/월 전환 + 기간 합계)

## 10. 하지 않는 것 (Non-goals)
수입 기록 / 카테고리 / 예산 설정 / 통계(차트·카테고리 분석) / 은행·카드 연동 /
로그인·동기화 / 월간 분석 화면(차트·카테고리 분석) / 설정 화면 시안 / 다크모드

## 11. 미정 사항
- 영수증 아카이브 정렬 순서, 기록 0건인 날의 처리
